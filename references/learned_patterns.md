# Learned Patterns

This file documents drawio XML patterns that were learned from user-provided before/after examples. Each entry includes the problem, the before/after diff, and the generalized solution.

## How to Add a New Pattern

When the user provides before/after drawio files for a pattern you don't recognize:

1. Diff the two files at the XML level
2. Identify the structural change (new cells, modified attributes, style changes)
3. Write a generalized description of the pattern
4. Include the key XML snippet (before → after)
5. Append the entry here with a clear date and description
